# core-models

Shared LLM provider layer for [mast](https://github.com/go-steer/mast) and
[core-agent](https://github.com/go-steer/core-agent): OpenAI-compatible Chat
Completions (Vertex MaaS, xAI, vLLM, SGLang, Ollama), OpenAI Responses,
Anthropic, and Gemini, behind one contract with normalized usage reporting.

**Status:** design only. See [`docs/design.md`](./docs/design.md).
